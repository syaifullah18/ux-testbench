{#- Shared for every page: the stylesheets, the Tailwind theme, and the colour tokens. Both the CDN build and the compiled build (LOCAL_ASSETS=1) read their theme from the same CSS custom properties, so one definition serves every page and each project's own colour reaches all of them. tailwind.config.js maps the same names for the compiled build; keep the two in step when adding a token. Two things live here: 1. The brand scale. A project sets one primary colour in project.yaml; the 50–950 steps are tints and shades of it, computed below, so a page can reach for a lighter or darker version of the brand without hard-coding a second palette that stops matching. `brand` means 500. 2. The surface tokens — `surface`, `card`, `line`, `ink` and friends. These are what make one set of markup work in both themes. Writing `bg-card text-ink` gives a card that is white with near-black text in the light theme and near-black with white text in the dark one, because the token flips, not the class. Hand-writing `dark:` on every element is how you end up with a dark card whose heading is still `text-ink` and therefore invisible. Reach for `dark:` only for a genuine one-off. -#} {%- set brand = project.brand if project else {'primary': '#2563EB', 'nav': '#0F172A'} -%} {%- macro rgb(hex) -%} {{ hex[1:3]|int(base=16) }} {{ hex[3:5]|int(base=16) }} {{ hex[5:7]|int(base=16) }} {%- endmacro -%} {#- tint mixes the colour with white, shade with black; `p` is how much of that is mixed in. -#} {%- macro tint(hex, p) -%} {%- set r = hex[1:3]|int(base=16) -%}{%- set g = hex[3:5]|int(base=16) -%}{%- set b = hex[5:7]|int(base=16) -%} {{ (r + (255 - r) * p)|round|int }} {{ (g + (255 - g) * p)|round|int }} {{ (b + (255 - b) * p)|round|int }} {%- endmacro -%} {%- macro shade(hex, p) -%} {%- set r = hex[1:3]|int(base=16) -%}{%- set g = hex[3:5]|int(base=16) -%}{%- set b = hex[5:7]|int(base=16) -%} {{ (r * (1 - p))|round|int }} {{ (g * (1 - p))|round|int }} {{ (b * (1 - p))|round|int }} {%- endmacro -%} {#- Set the theme class before the first paint, or a dark-theme visitor gets a white flash on every page load.
