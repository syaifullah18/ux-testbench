{#- Light/dark switch. The class is already on by the time this renders — _head.html sets it before the stylesheet loads, so there is no flash of the wrong theme. This button only flips it and remembers the choice. The choice is a per-viewer convenience, so localStorage is the right place for it: it never needs to reach the server or another device. Every access is wrapped, because a private window or blocked site data makes it throw. `toggle_on_nav` is for the coloured app bar in base.html, where a card-coloured button would read as a light patch punched out of the nav. Include it as `{% with toggle_on_nav = true %}{% include "_theme_toggle.html" %}{% endwith %}`. -#}
