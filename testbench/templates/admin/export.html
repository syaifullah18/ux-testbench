How the files are laid out

  • Column names are ids

    Each question and task id becomes part of a column name, so ids you keep stable keep your columns stable.

  • One row per person

    In the A/B module, each variant and task has its own columns, for example A_date_answer and B_date_time_s.

  • Opens in spreadsheets

    UTF-8 with a byte order mark, so accents and non-Latin text show correctly in Excel and Numbers.
